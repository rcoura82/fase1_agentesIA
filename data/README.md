# Dados do projeto

Este diretório deve receber os arquivos do dataset Brazilian Ecommerce (Olist) utilizados para a análise de negócio e os testes dos agentes de IA.

Estrutura sugerida:

- olist_customers_dataset.csv
- olist_orders_dataset.csv
- olist_order_items_dataset.csv
- olist_order_payments_dataset.csv
- olist_order_reviews_dataset.csv
- olist_products_dataset.csv
- olist_sellers_dataset.csv
- olist_geolocation_dataset.csv
- product_category_name_translation.csv

Se os arquivos forem grandes, prefira manter os dados em um armazenamento externo ou usar Git LFS para versionamento controlado.
