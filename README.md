## Dataset

O projeto utiliza o dataset Brazilian Ecommerce da Olist como base analítica para validação de hipóteses de negócio, priorização operacional e desenho dos agentes de IA.

Os arquivos do dataset devem ficar armazenados na pasta `data/`, com a estrutura original do Kaggle ou em um diretório equivalente já configurado localmente no ambiente do projeto.

## Observação

Este repositório reúne a base estratégica da Fase 1 e a documentação do desenho inicial da solução. A partir do dataset e do dicionário de dados, os entregáveis podem ser refinados com evidências quantitativas para validação da proposta executiva e dos agentes propostos.
